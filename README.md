A tiny program that writes one line of weather forecast to a text file. The
line is a single sentence of at most 140 characters: a forecast for an
invented city, Mizzleham, where the drizzle is so light the forecast calls
it "atmospheric moisture" and your hair calls it betrayal. It is written to
make a bored commuter smile on the way to work.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
